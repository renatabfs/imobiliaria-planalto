# Planalto Imóveis

Landing page responsiva para uma imobiliária fictícia, criada como projeto de demonstração de front-end.

**Site:** https://renatabfs.github.io/imobiliaria-planalto

## Funcionalidades

- Filtro dinâmico de imóveis por tipo (casa, apartamento ou terreno) e por valor máximo
- Lista atualizada na hora, ordenada pelo menor preço
- Formulário de contato com validação de nome e telefone
- Layout responsivo, que funciona bem no celular e no computador
- Modo escuro automático, conforme a preferência do dispositivo
- Acessibilidade: navegação por teclado, rótulos nos campos e foco visível

## Tecnologias

- HTML5
- CSS3 (variáveis, Grid e Flexbox)
- JavaScript (sem bibliotecas)

## Como rodar

Baixe o projeto e abra o arquivo `index.html` no navegador. Não precisa instalar nada.

## Observação

A empresa, os imóveis e os valores são fictícios. O projeto serve apenas para demonstração.
